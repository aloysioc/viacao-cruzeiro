# Architecture Decision Records (ADRs)

Os ADRs registram decisões de arquitetura, segurança, operação e governança que afetam a solução produtiva.

Uma decisão aceita não deve ser alterada silenciosamente: a mudança deve ser registrada em um novo ADR, indicando qual decisão anterior foi substituída.

| ADR | Decisão | Estado |
|---|---|---|
| [ADR-001](0001-evolucao-lab-para-producao.md) | Evoluir o repositório do LAB para uma base controlada de produção | Aceita |
| [ADR-002](0002-repositorio-e-ingestao-csv.md) | Definir o repositório e a entrega definitiva dos CSVs antes de habilitar a agenda | Em validação pelo cliente |
