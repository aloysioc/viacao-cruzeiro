# Runbooks operacionais

Runbooks serão criados e validados antes do go-live para:

- publicação e rollback da Function;
- ausência ou atraso de CSV;
- arquivo inválido, duplicado ou corrompido;
- reprocessamento autorizado;
- falha no envio de e-mail;
- indisponibilidade ou fallback do Azure OpenAI;
- habilitação e desabilitação controlada da trigger;
- revisão de alertas, custos e acessos.
