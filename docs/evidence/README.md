# Evidências de implantação

Cada gate deverá registrar uma evidência curta, revisável e sem segredos. A evidência deve conter data, executor, escopo, validações realizadas, resultado do `what-if`, recursos criados ou alterados e próximos passos.

Não registrar chaves, connection strings, tokens, conteúdo de CSVs reais, dados pessoais ou URLs temporárias.
