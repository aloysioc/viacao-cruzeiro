# Gate C1 — Fundações

Planejado para criar, após a aprovação do Gate B:

- Storage Account com Azure Data Lake Storage Gen2;
- filesystems `raw`, `reference` e `output`;
- Key Vault;
- Log Analytics Workspace e Application Insights;
- identidade gerenciada da Function;
- diagnósticos, retenção e configurações de segurança aprovadas.

O desenho final depende da confirmação do destino, método e periodicidade de entrega dos CSVs.
